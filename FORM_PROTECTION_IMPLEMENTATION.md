## Механизмы защиты

### Клиентская защита
1. **Класс `FormProtection`** - универсальный модуль защиты
2. **Set() коллекция** - отслеживание защищенных кнопок
3. **Физическая блокировка** - `disabled=true`
4. **Визуальная индикация** - класс `btn-loading` со спиннером
5. **Таймаут** - автоматическая разблокировка через 30 секунд
6. **preventDefault()** - блокировка событий

### Серверная защита
1. **Nonce-проверка** - защита от CSRF-атак
2. **Временной интервал** - проверка на повторные запросы (для корзины)
3. **Валидация данных** - проверка ИНН и других полей

## Как использовать

### Автоматическая защита через класс
Добавьте класс `protected-button` к кнопке отправки:
```html
<button class="trueButton protected-button" id="submitBtn">Отправить</button>
```

### Программная защита
```javascript
if (typeof window.formProtection !== 'undefined') {
    window.formProtection.protectButton($('#myButton'));
}
```

### Защищенный AJAX-запрос
```javascript
window.formProtection.createProtectedAjax({
    url: allAjax.ajaxurl,
    button: $('#submitBtn'),
    success: function(response) {
        // Обработка успешного ответа
    },
    error: function(xhr, status, error) {
        // Обработка ошибок
    }
});
```

## Конфигурация

### Настройка модуля защиты
```javascript
window.formProtection = new FormProtection({
    timeout: 30000,           // Таймаут разблокировки (мс)
    loadingClass: 'btn-loading',  // CSS класс для загрузки
    successClass: 'btn-success',  // CSS класс для успеха
    errorClass: 'btn-error',      // CSS класс для ошибки
    showLoading: true,       // Показывать индикатор загрузки
    blockOnError: true,      // Разблокировать при ошибке
    disableOnSuccess: true   // Оставлять заблокированной при успехе
});
```

## Тестирование

### Проверка защиты
1. Откройте любую защищенную форму
2. Нажмите на кнопку отправки
3. Попробуйте нажать повторно - кнопка должна быть заблокирована
4. Проверьте индикацию загрузки (спиннер)
5. После успешной отправки кнопка должна остаться заблокированной
6. При ошибке кнопка должна разблокироваться

### Проверка таймаута
1. Откройте форму и начните отправку
2. Отключите интернет (симуляция ошибки сети)
3. Подождите 30 секунд - кнопка должна автоматически разблокироваться

## Мониторинг и логирование

Для мониторинга повторных отправок можно добавить логирование:

```php
// Добавить в функции AJAX
```
